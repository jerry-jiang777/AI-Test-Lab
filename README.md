## 1.这个项目解决什么问题？

之前存在学习颗粒度过大，零散化严重，知识没有连续性，学了很多但是没有作品，即缺少一个主项目，所有的知识都应该围绕一个项目开展的。最大的问题就是 "没有输出"。

## 2.为什么要做它？

解决上述存在的问题、所以开始这个项目的目的就是：不再以“学知识”为目标，而是以“完成项目”为目标。
