## Day1

### 1.1 今天学习到了什么？

今天主要学习了开始AI-Test-Lab项目的背景，主要是结合以往的学习经历，学习内容跨度大，知识不连续且没有输出，所以开始该项目。学习的目的由原来的"学习知识为目标"改成“基于项目本身，展示作品顺带输出”

### 1.2 有什么疑问？

该项目目录有很多，并且后期需要安装DeepEval和OpenCompass等框架，因为每个框架都有自己的运行规则和项目目录要求，我后面把这两个框架都安装到这个一个项目种，同时运行不会相互影响吧！

### 1.3 今天最大的收获是什么？

收获：明确了该项目开始的目的，知道了后期的学习路线，做到心中有数！

## Day2

### 2.1 今天学到了什么？

项目开始前，别着急写代码，好的系统开发流程是从从需求分析开始的，需要先做好的是系统的架构设计(好的架构是难得的)；系统架构总结一句话就是：说明了不同的文件应该放到哪里？

### 2.2 有什么疑问？

今天关于架构的设计更多的是偏向理论的，目前没有过多的疑问。

### 2.3 今天最大的收获是什么？

之前以为系统中最重要的是代码，现在已经明确了，更重要的是系统架构的设计，好的架构设计会让整个系统变得拓展性好，不至于出现"牵一发而动全身"的情况，另外做好分层的设计，满足高内聚低耦合的原则。
